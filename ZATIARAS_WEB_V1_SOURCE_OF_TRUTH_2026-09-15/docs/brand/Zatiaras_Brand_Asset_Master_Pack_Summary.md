# Zatiaras Juice — Brand Asset Master Pack

**Source:** `Zatiaras_Brand_Asset_Master_Pack_V1_0_12_Halaman.pdf`  
**Function:** Production asset system, technical usage rules, vendor handoff, QA, and cup-branding specifications.

---

## 1. Purpose

The Brand Asset Master Pack functions as the official source of truth for production assets used across:

- print
- digital
- signage
- packaging
- cup production

Its role is to reduce inconsistency, prevent logo modification, and make vendor execution predictable.

---

## 2. Logo Asset System

Three official logo forms are defined.

### 1. Standalone Z-Cup
Use for:
- icon
- avatar
- favicon
- compact spaces
- secondary brand symbol

### 2. Primary Horizontal Lockup
The default master logo for most applications.

Consists of:
- Z-Cup symbol
- ZATIARAS JUICE wordmark

### 3. Wordmark Only
Used where the symbol is not required.

---

## 3. Asset Hierarchy

### Primary
Primary horizontal lockup.

Use as the default logo for most brand applications.

### Secondary
Standalone Z-Cup.

Use for icons, compact spaces, avatars, and secondary applications.

### Tertiary
Wordmark only.

Use when a symbol is not necessary.

## 4. Logo Protection & Clear Space

The document defines minimum clear-space requirements around:

- standalone Z-Cup
- horizontal primary lockup

## 8. File Naming Convention

The pack recommends a consistent naming structure.

Example:

`ZJ_LOGO_PRIMARY_MAGENTA_v01.svg`

The naming pattern should communicate:

- brand abbreviation
- asset type
- color/variant
- version
- file format

Avoid vague names such as:

- `final.svg`
- `final-final.svg`
- `new-logo.png`

---

## 10. Vendor Handoff Guide

Vendors should follow six principles.

1. Use official files only.
2. Do not modify the logo.
3. Follow exact specifications.
4. Request a proof.
5. Escalate technical limitations.
6. Obtain approval before mass production.

### Reject production if

- logo is redrawn
- proportions are changed
- logo is distorted
- color is incorrect
- wordmark is modified
- unofficial files are used

---

## 11. Final QA Checklist

Before publishing or producing an asset, verify:

1. Correct official asset is used.
2. Correct color variant is used.
3. Logo geometry has not changed.
4. Clear space is respected.
5. Minimum size is met.
6. Typography is consistent.
7. Product imagery is realistic and appropriate.
8. Approved messaging is used.
9. Correct cup lockup is used.
10. Proof has been reviewed.
11. Export format is correct.
12. Final result is checked at actual size.

## 12. 22 oz Cup Branding Overview

The pack defines a specific system for the standard transparent 22 oz cup.

### Main rules

- Use one-color printing.
- Use Heritage Magenta.
- Use the horizontal primary lockup.
- Apply the logo to one side.
- Keep the logo visually centered.
- Maintain enough contrast against the drink.

### Why one color

A single consistent color simplifies production while keeping recognition strong and reducing unnecessary visual variation.

---

## 13. Exact Logo Placement on Cup

### Rules

1. Use the horizontal primary lockup only.
2. Print on one side only.
3. Visually center the logo.
4. Do not wrap the logo around the cup.
5. Do not stack the symbol above the wordmark.
6. Maintain clear space around the logo.

Final placement still needs validation using an actual supplier cup.

The document demonstrates the logo against multiple drink colors, including:

### Pass criteria

---

## 15. Cup Do & Don't

### Do

- use the official horizontal primary lockup
- print on one side
- keep the logo visually centered
- keep size consistent

### Don't

- stretch
- condense
- rotate
- recolor arbitrarily
- stack the symbol and wordmark
- place the logo too close to the rim
- repeat or wrap the logo around the cup

---

## 16. Approval Gate

Cup production follows three gates:

1. **Digital Proof Review**
2. **Physical Sample Check**
3. **Final Approval**

Any altered or modified logo should be automatically rejected.
