# Agent rules

Before implementing any visual component:

1. Identify the task type.
2. Read the page references above.
3. Use official repository assets.
4. Do not redraw or regenerate source assets.
5. If the PDF does not support a visual claim/rule, do not invent it.
6. If a product/software decision goes beyond the brand PDFs, treat it as a product/UX decision and document it separately.

---

# Important distinction

The official PDFs define **brand identity and approved applications**.

They do not automatically define:
- web information architecture,
- checkout UX,
- backend architecture,
- payment state machine,
- database model,
- SEO architecture.

Those are governed by the other project documents.
