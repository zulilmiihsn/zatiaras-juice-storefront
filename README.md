## ⚡ Overview

**Zatiaras Juice Web** serves as the digital front door for the Zatiaras Juice brand. It highlights healthy juice offerings, menu variations, nutritional value, customer testimonials, and direct ordering links.

## ✨ Features

- 🌿 **Clean & Fresh Aesthetics**: Vibrant, appetite-appealing color palette tailored for beverage retail.
- 📱 **Fully Responsive**: Optimized for mobile, tablet, and desktop viewports.
- 📋 **Interactive Menu & Catalog**: Categorized drink options with details and pricing.
- 💬 **Direct WhatsApp/Call-to-Action**: One-click ordering button directing customers to chat for instant purchases.
- ⚡ **Optimized Performance**: Fast loading speeds with modern image optimization.

## 🛠️ Tech Stack

- **Framework**: React / Next.js
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Deployment**: Vercel

## 🚀 Getting Started

```bash
# Clone repository
git clone https://github.com/zulilmiihsn/zatiarasjuice-web.git
cd zatiarasjuice-web

# Install dependencies
pnpm install # or npm install

# Run development server
pnpm dev
```
